资料与规范 / 逐页阅读

设定集阅读网站规划

版本：草案 0.5｜2026-10-19

目标与形态

做一个私人的、本地优先的「小白龙同志设定集」阅读站，方便用户与后续工作会话读到相同资料。项目 Markdown 是正本，网页是阅读层；不登录、不收集访问数据、不连接外网，不公开部署。

页面结构

  1. 首页：当前用户确认的夜路主视觉、角色一句话介绍、设定版本和更新状态。
  2. 角色主设定：身份、外貌锚点、性格、主色板、日常态与龙族态的差别。
  3. 穿搭档案：夜路碎花裙作为一套确认喜欢的生活穿搭；标准造型方向采用短外套、雾紫上衣与高腰百褶裙提案；七张用户穿搭案例单独归档。
  4. 十系列：代表分镜、规划/草稿/确认状态和角色独立性边界。
  5. 作品与参考：用户确认的夜路图和补充脸部表情图本地显示；未确认草稿独立标注。每张图注明可继承与排除的特征、现实参考或虚构场景。
  6. 工具研究：GitHub 工具、生成技能与服装案例的摘要、来源链接和适用判断。
  7. 制作记录：用户反馈、修改优先级、接力事项。

图像与隐私

  • 用户明确选定的夜路图可作为本地网站主视觉；项目源文件不改动，只复制到本目录。
  • 其他私人原图和封存卷默认不复制进网站。将来只在明确需要时挑选，且始终不做公开部署。
  • 用户未确认的生成候选放入“草稿”而非首页主视觉。

阅读与维护

  • 本地静态 HTML/CSS/JavaScript，无数据库、无外部字体和脚本，直接读取同目录图片。
  • 全站搜索、系列状态筛选、图片大图查看和来源说明。
  • 页面文案从 Markdown 的已确认信息整理，Markdown 仍是 AI 后续会话最稳定的读取方式。
  • 移动端可读，键盘可操作，重点信息不依赖颜色单独表达。

已有项目工具

项目 archive/site/ 已有私人档案检索站，用于查找结构化记忆和影像目录；新站聚焦角色设计、作品状态和提示词，不重复做封存资料搜索。新站与旧站都只在本机使用。

本地原型状态

已建立 site/ 静态阅读站：有档案首页、十五份 Markdown 阅读页、关键词搜索、作品对照与大图查看、用户提供的穿搭参考板、衣橱逐步登记、十系列状态、手机窄屏布局。页面只读取本项目内的 Markdown 与图片，没有外部字体或脚本。根目录的 启动设定集.command 可在本机启动服务器并打开页面；不公开部署。

32套提示词工作台已接入，支持分类、优先级、全文搜索、独立TXT下载、全文复制、参考职责与案例链接。第二批6张新拼板独立展示，重复图复用。
